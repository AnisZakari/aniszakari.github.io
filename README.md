# Personal Blog

A Jekyll blog using the Chirpy theme, hosted on GitHub Pages.

## Setup

1. Update `_config.yml`:
   - Change `url` to your GitHub Pages URL
   - Update `author.github` with your GitHub username
   - Update timezone if needed

2. Install dependencies:
   ```bash
   bundle install
   ```

3. Test locally:
   ```bash
   bundle exec jekyll serve
   ```

4. Deploy to GitHub Pages:
   - Push to GitHub
   - Enable GitHub Pages in repository settings
   - Select "GitHub Actions" as the source

## Features

- ✅ Modern, responsive design
- ✅ LaTeX/MathJax support
- ✅ Syntax highlighting
- ✅ Dark mode
- ✅ SEO optimized
- ✅ Tag and category support

## Notes

- Posts are in `_posts/` directory
- Images are in `assets/` directory
- The theme handles image sizing automatically
