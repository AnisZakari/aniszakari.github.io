Solution

The error is strange because there is an arm64 wheel of the package.
The first thing I would recommand you to do is to try this command:

pip3.9 install fasttext --force-reinstall --no-cache-dir

If this doesn't work, let's try something else. Sometimes xcode is the key to solve this problem, try the following command:

xcode-select --install

If it doesn't solve the issue then it might be because xcode is not up-to-date.
Try this:

sudo rm -rf /Library/Developer/CommandLineTools
xcode-select --install

A popup will appear and guide you through the rest of the process.

Note

I encountered the same problem with psycopg2 or pycld2. pip3.9 install --force-reinstall --no-cache-dir worked like a charm.
