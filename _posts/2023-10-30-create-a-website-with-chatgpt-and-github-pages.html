What is GitHub Pages ?

GitHub Pages is a GitHub service for hosting static websites directly from repositories.

It's free, user-friendly, supports custom domains, and integrates with Jekyll. Additionally, it leverages Git's version control.

However, it's limited to static content, has a 1GB repository size cap, and lacks advanced backend features like databases.
So if you’re expecting a lot of traffic or want complex features, paying for a great hosting service would be the way to go.

Prohibited uses :
GitHub Pages is not intended for or allowed to be used as a free web-hosting service to run your online business, e-commerce site, or any other website that is primarily directed at either facilitating commercial transactions or providing commercial software as a service (SaaS). GitHub Pages sites shouldn't be used for sensitive transactions like sending passwords or credit card numbers. See GitHub's documentation on prohibited uses for more details.

Setup the github project

I suppose that you are already familiar with the basics of github and git commands, if it's not the case, there are plenty of free resources on the net, please check them before diving into this tutorial.

Once you are logged in to your Github account, go to your repositories and create a new one

Note that in order to publish a GitHub Pages site, your repository must be public. Private repositories are not supported for hosting GitHub Pages websites for free

After the repository has been created, you can copy its link.

Now you can clone the project locally using either a terminal window or the built-in terminal in the IDE of your choice

[code language="bash"]git clone link-to-your-github-project.git
cd your-github-project[/code]

ChatGPT to the rescue

Now we'll have ChatGPT do most of the work for us, the idea is to get him generate the components of our website, that is to say:

  • index.html:

    file that contains the structure and content of web pages using HTML markup. They define the semantic elements like headings, paragraphs, links, etc

  • style.css:

    file to add styling to web pages using CSS code. They control visual elements like colors, layout, fonts, etc.

  • script.js:

    file to add interactivity and dynamic behavior to web pages using JavaScript code. They enable functionality like click events, animations, data manipulation, etc.
